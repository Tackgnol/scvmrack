# Scvm Rack — v0.4.3

**Release date:** 2026-06-24
**Type:** Patch — GM party-name form hardening

A focused GM dashboard polish pass so party creation stays readable and catches
overlong names before the request leaves the browser.

---

## Highlights

- **Readable party-name input.** Text in the yellow GM overview party-name field
  now renders in black, matching the field label and preserving the Mörk Borg
  yellow-paper look without losing contrast.
- **100-character party-name limit.** The create-party form now validates party
  names in the browser and blocks submit when the name is too long.
- **Localized validation feedback.** The party-name validation message is
  available in English and Polish.

## Under the hood

- The GM overview create-party form now uses `react-hook-form` with a Zod
  resolver, replacing the previous local input state.
- Browser coverage now asserts the black-on-yellow input text and the over-limit
  validation path.

## Verification

- `npm run test:browser -- test/browser/pages/GmOverviewPage.test.tsx`
- `npm run build`
- `npm run lint`
