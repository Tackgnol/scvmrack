# Scvm Rack - v0.5.1

**Release date:** 2026-06-28
**Type:** Patch - Owlbear Rodeo install fix

This patch fixes Owlbear Rodeo extension installation for the public manifest.

---

## Fixes

- The public OBR manifest and extension entry assets now send CORS headers from the frontend container, so Owlbear can fetch `manifest.json` during install.
- The OBR manifest files now report version `0.5.1`.
