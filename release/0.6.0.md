# 0.6.0 - Beta, miseries, and sturdier sessions

Scvmrack enters Beta with a new Misery track and a broad reliability pass across character ownership, monitoring, and the Owlbear extension.

- **Beta milestone** — The app now identifies itself as Beta, and all package and Owlbear manifest metadata reports version 0.6.0.
- **Miseries** — Character sheets include the seven-step Misery track, with controls for players and GMs.
- **Reliable recovery** — Missing or forbidden characters and anonymous-to-signed-in session transitions recover cleanly without deleting character data or getting stuck.
- **Actionable monitoring** — GlitchTip filters expected browser, navigation, and API noise while retaining release metadata and private source-map diagnostics for real failures.
- **Owlbear hardening** — Room visibility, enemy cards, token binding, and session handling are more consistent and resilient.
