# Scvm Rack — v0.3.0

**Release date:** 2026-06-05
**Type:** Minor — character engine moved off the database

This release re-homes character generation and reads from the database into the
application itself, in preparation for the alpha. Mostly under the hood — your
characters and sheets work exactly as before.

---

## Highlights

- **New generation engine.** Random character generation now runs in the app via
  a seedable roller instead of database-side randomness — the groundwork for
  faster, more portable, and more testable generation.
- **Reads moved in-app.** Fetching a full character (with localized data) and
  saving edits no longer depend on database stored procedures.
- **Alpha prep.** Internal cleanups and consistency work ahead of the public
  alpha.
