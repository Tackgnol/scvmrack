# Scvm Rack — v0.3.4

**Release date:** 2026-06-07
**Type:** Patch — clearer account controls and a locale-consistent character list

A small UX follow-up to v0.3.3.

---

## Highlights

- **Clearer account controls.** The header now shows labeled buttons — "Logged In"
  / "Log Out" (and "Log In / Sign Up" when signed out) — instead of bare icons,
  so it's obvious at a glance whether you're signed in.
- **Consistent character list.** The character list (and its dates) now render in
  English, matching the English-only app, regardless of your browser language.

## Under the hood

- `GET /api/characters` accepts an explicit `locale` query parameter, falling
  back to the request's `Accept-Language`; the frontend pins it to `en`.
- Theme styling for the new labeled header auth buttons.

## Verification

- Backend unit + frontend unit / browser suites pass; type-check and lint clean.
