# 0.7.0 - Custom Classes

## Browse before you roll

Explore public pages and classes without starting a guest session. A guest session begins when you choose to roll a scvm or start a draft.

Returning players keep their existing session. Private sheet links offer recovery when a session is missing, without creating a new guest who cannot access the original scvm. Character creation also works for the current visit when browser storage is blocked, after you acknowledge the privacy notice.

## Forge and evolve your own classes

Signed-in GMs can forge Custom Classes with their own origins, abilities, reference tables, starting items, and Getting Better rules. Drafts save automatically, and a class that existing scvm already use gets a new version when you save changes—those scvm keep their original rules.

Book Class Omen rolls now match the printed book: Esoteric Hermit and Heretical Priest use d4; the other Book Classes use d2.

## Put classes at the table

A GM can add Book and Custom Classes to a Party Class Pool. New scvm created for that party use the pool, while Owlbear rooms can use the same class choices.

The GM tab now shows everyone what party control can do. Visitors can preview the dashboard and sign up to run a warband; guest scvm come with them when they create an account.

## Share responsibly

Creators can publish a Custom Class for other GMs to discover and add to their pools. Public classes show their attribution and can be reported by anyone, including signed-out rightsholders. Reports receive human review, serious reports are flagged, authors receive reasons for takedowns, and can dispute a decision in the app or by email. Moderators can review a GM's prior class removals and restrict new class creation without blocking their existing classes or characters.

## Terms, contact, and privacy

The footer now links to the Terms, Contact, Privacy, and report pages. The FAQ explains who can forge and share classes, how versions work, and where to contact the zine curator.
