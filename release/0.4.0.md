# Scvm Rack — v0.4.0

**Release date:** 2026-06-23
**Type:** Minor — parties, the character creation flow, and Polish

The big one: warbands you can share, a proper scvm creation flow, and the return
of Polish.

---

## Highlights

- **GM-owned parties.** A game master can create a party, share an invite link,
  and watch the warband fill up. Players open the link and bind a scvm to the
  table — no account juggling required.
- **Live warband updates.** The GM overview and the player party view stream
  changes as they happen (HP, stats, who's connected) over a live connection, so
  the table stays in sync without refreshing.
- **Character creation flow.** A guided `/character/create` path: pick a class,
  go classless, or let the dice decide, preview a fully rolled scvm, re-roll any
  section, then forge it. Guests keep a single scvm.
- **Polish is back.** Polish is re-enabled with a redesigned header language
  toggle, plus broad localization across saved classes, modifiers, the GM screen,
  and combat tooltips.

## Under the hood

- New party system: GM-owned party entity, signed invite links, character
  binding, member kick/leave/replace, and a Server-Sent-Events stream behind the
  shared-auth credentialed fetch path (works inside the itch.io embed).
- Stateless creation drafts driven by the seedable in-app roller; one-scvm-per-guest
  enforced on the backend.
- The character list honors `Accept-Language`; the language bundle for the
  detected locale loads on first entry.
- CI/deploy fixes for the dev (canary) stack and the integration test stage.

## Verification

- Backend unit + frontend unit / browser suites, type-check, and lint pass with
  existing warnings only.
