# Scvm Rack - v0.5.0

**Release date:** 2026-06-28
**Type:** Minor - Owlbear Rodeo extension

Scvmrack now runs inside Owlbear Rodeo: players can keep their sheet open in the room, bind scvms to scene tokens, and let the GM see a live table roster with compact card peeks.

---

## Owlbear Rodeo

- **Embedded player and GM views.** The `/obr.html` extension route shows an editable player sheet for players and a live bound-token roster for GMs.
- **Token binding.** Players can bind or re-bind a selected token to their current scvm. The button is disabled until a token is selected, and selected bound tokens are labeled with the scvm name.
- **Token card peek.** Bound tokens expose a compact "View scvm" context-menu card with HP, Omens, silver, combat targets, armor DR, equipment, traits, and active modifiers.
- **GM roster.** GMs see all scvms bound in the Owlbear room, with the same warband row model used by the main party view.
- **Room promotion.** Signed-in GMs can move an Owlbear room into a durable scvmrack party and get invite/manage links.
- **OBR manifest polish.** The extension uses the Scvmrack logo asset for its Owlbear listing and app identity.

## Fixes

- Armor damage reduction now shows in the party/GM/OBR warband rows when a scvm has armor such as leather equipped.
- Warband DR breakdowns now use the same modifier filtering as the main sheet, including excluded contexts and custom modifiers.
- OBR card reads are room-gated by the `(roomId, characterId)` binding, so a character UUID alone is not enough to fetch a card.
- The OBR extension shell keeps the top controls available while scrolling the embedded sheet.
