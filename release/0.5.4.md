# Scvm Rack - v0.5.4

**Release date:** 2026-06-30
**Type:** Patch - Owlbear Rodeo enemy popovers

This patch moves player-facing enemy cards out of the embedded character sheet
and into token-anchored Owlbear Rodeo popovers.

---

## Fixes

- Player enemy cards now open from the bound enemy token context menu instead
  of rendering above the player's character sheet.
- Enemy popovers try to anchor to the selected token bounds, falling back to the
  context-menu button when Owlbear cannot transform the token position.
- Player enemy popovers use the safe enemy-card projection; GM popovers still
  open the full editable enemy form.
- The OBR manifest now reports version `0.5.4` and points at a fresh popover
  URL.
