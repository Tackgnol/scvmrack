# Scvm Rack — v0.3.3

**Release date:** 2026-06-07
**Type:** Patch — first-run/privacy polish and QA cleanup

A small follow-up to the launch pass, driven by an app-wide QA sweep. It fixes
the order of first-run storage consent, smooths the loading experience, and
trims a half-finished feature rather than ship it broken.

---

## Highlights

- **Consent before creation.** On your first visit, Scvm Rack no longer creates a
  guest character before you accept the data/storage notice. Nothing is written
  until you choose "Save Preferences."
- **Animated loading sheet.** While your character is being prepared or loaded,
  the sheet now shows an on-theme skeleton (with stable sizing) instead of a
  blank or jumping layout.
- **English-only, for now.** The language switcher and the (non-functional)
  Polish translation have been removed. The app is English-only while
  multi-language is reworked — nothing else changes for you.
- **Consistent credit.** The FAQ footer now uses the same
  "Ockult Örtmästare Games and Stockholm Kartell" credit as the rest of the site.

## Under the hood

- Utility / API-looking paths (`/health`, `/openapi.json`, `/docs`, `/test/*`)
  now return `404` instead of the app shell, so monitoring and exposure scans
  aren't confused. The real `/api/health` is unchanged.
- Added a production release gate and QA notes (`docs/qa/`) — a repeatable
  ship / no-ship checklist and the findings this release came from.
- The i18n machinery and Polish bundle are intentionally retained (disabled) for
  a future re-enable.

## Verification

- Frontend unit: `290 passed` · browser: `252 passed`
- Type-check and lint: clean
- Backend code unchanged this release.
