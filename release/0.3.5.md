# Scvm Rack — v0.3.5

**Release date:** 2026-06-07
**Type:** Patch — canonical sheet URLs and plain-text saves

A small bugfix release for character routing and saved text.

---

## Highlights

- **Clean character URLs.** Generating or selecting a new scvm from an existing
  sheet now lands on `/character/<id>` without carrying a stale `?character=...`
  query parameter.
- **Real not-found route.** Opening `/character/` now shows the 404 page instead
  of an empty app state.
- **Plain-text saves.** Character text fields now save apostrophes and typed
  punctuation as plain text instead of returning HTML entities such as
  `It&#x27;s`.

## Under the hood

- Character-sheet route selection now rewrites active sheet URLs to the canonical
  path form and clears only the legacy `character` query parameter.
- `/character/` has an explicit not-found route.
- Backend character update sanitization now trims and length-limits text without
  HTML-encoding persisted API values; React remains responsible for escaping at
  render boundaries.

## Verification

- Backend unit suite passes; frontend route unit tests, page browser tests,
  production build, and lint pass with existing warnings only.
