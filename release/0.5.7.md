# 0.5.7 - Owlbear package hardening

Owlbear room character visibility now uses one shared rule across roster,
enemy-card, and package-backed room APIs: a scvm is visible when it is bound in
the room or belongs to the party attached to that room.

The Owlbear panel transport now goes through the app's normal OpenAPI client, so
CSRF/session handling stays consistent with the rest of Scvmrack. The OBR
manifest now reports version 0.5.7 and reloads the current panel entrypoint.
