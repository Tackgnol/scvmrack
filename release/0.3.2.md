# Scvm Rack — v0.3.2

**Release date:** 2026-06-06
**Type:** Patch — launch-readiness fixes and reliability

A pre-launch pass focused on the character editor's reliability, inventory
correctness, and the polish people see first. Sheets and characters are
unchanged — this is fixes and hardening.

---

## Highlights

- **No more lost edits.** The character sheet now saves reliably under fast,
  back-to-back edits: changes made while a save is in flight are no longer
  dropped or reverted, transient failures retry automatically, and an edit made
  right before leaving the page is still saved.
- **Inventory fixes.** Unequipping armor and editing items behave correctly, and
  two genuinely different items that happen to share a name (e.g. a d4 and a d6
  "Dagger") no longer merge into one stack.
- **Shareable links.** Links to Scvm Rack now render a proper preview card on
  Discord/Twitter/etc., and the site ships a sitemap for search engines.
- **Known issues.** Added a "Known issues" entry to the FAQ covering the
  remaining stacked-item editing quirk and its workaround.

## Under the hood

- Restructured the backend API into clear repository / service / controller
  layers (characters, equipment, feedback) and split the large character hook on
  the frontend — no behavior change, easier to maintain and test.
- Hardened character generation (deterministic shared-roll weapons, faster item
  lookups) and tightened a database field limit.
