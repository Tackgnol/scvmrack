# Scvm Rack - v0.5.3

**Release date:** 2026-06-30
**Type:** Patch - Owlbear Rodeo enemy setup

This patch removes the manual "move room first" enemy gate from the Owlbear
Rodeo GM enemy tab.

---

## Fixes

- Opening the GM enemy tab now prepares the room enemy board automatically.
- The enemy setup flow no longer asks for scvmrack login or manual party
  promotion before the GM can add enemies from Owlbear.
- The OBR manifest now reports version `0.5.3` and points at a fresh popover
  URL.
