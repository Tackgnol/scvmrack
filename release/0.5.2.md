# Scvm Rack - v0.5.2

**Release date:** 2026-06-30
**Type:** Patch - Owlbear Rodeo extension refresh

This patch forces Owlbear Rodeo to reload the current extension entrypoint after
the room binding and enemy management updates.

---

## Fixes

- The OBR manifest now reports version `0.5.2`.
- The OBR action popover URL is cache-busted so installed rooms load the current
  player actions, player-name labels, and room-scoped enemy management UI.
- The public OBR manifest and popover shell now send `Cache-Control: no-store`.
