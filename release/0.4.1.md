# Scvm Rack — v0.4.1

**Release date:** 2026-06-23
**Type:** Patch — Polish localization and party-flow fixes

A follow-up to v0.4.0 that sands down the Polish experience and unblocks a party
dead-end.

---

## Highlights

- **Item search is translated.** Looking up equipment on the Polish view now
  returns Polish item names instead of English ones.
- **Localized dates.** The character list now formats dates in the active
  language instead of always using English.
- **No more party dead-end.** A player whose only scvm is already bound to a
  party can now leave it — or roll/forge a fresh scvm — straight from an invite
  link, instead of being stuck.
- **Quiet "something changed" pulse.** When a value updates live, the GM warband
  strip gives a soft, motion-safe flash on just that scvm.
- **Creation flow polish.** The re-roll button is localized ("Przerzuć"), stat
  names and abbreviations are translated (Siła/Zwinność/Opanowanie/Wytrzymałość),
  and re-rolling one section no longer flashes every section's button.
- **Language in the URL.** Opening `/pl/...` or `/en/...` sets the language and
  then continues to the normal page.

## Under the hood

- Item search reads the selected locale (`i18n.language`) instead of the
  fallback-resolved one, which had pinned Polish searches to English.
- A bootstrap-time URL rewrite strips an optional `/{lang}/` prefix and seeds the
  language detector — no per-route duplication.
- Polish copy: the creation entry reads "Stwórz scvma", and the warband "rack" is
  now the grimmer "katownia".

## Verification

- Type-check, lint, and the affected frontend browser/unit suites pass.
