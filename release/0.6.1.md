# 0.6.1 - Getting Better and the Owlbear full-site handoff

## Getting Better

MÖRK BORG's Getting Better advancement has landed on the character sheet.

- **Get Better action** — a new action next to your scvm's identity lets you level up.
- **Preview, reroll, apply** — preview the roll first, reroll it if you don't like it, then apply it when you're happy.
- **Scum fixes** — Scum improvement abilities and specialty descriptions now read correctly instead of overlapping or falling back to English.

## Anonymous Owlbear handoff

Anonymous Owlbear players can now move from the embedded sheet to the full Scvmrack site in one click.

- **Open in full site** — Bound character tokens have a separate context-menu action that opens the character's full sheet in a new tab.
- **Ownership stays put** — A short-lived, single-use handoff carries the Owlbear session into the tab without transferring the character away from the embedded session.
- **Safe retry** — Blocked tabs and expired or already-used handoff links show a short retry prompt.

The existing inline **View scvm** card remains unchanged.

## Also in this release

- Owlbear ownership handling is more reliable after bumping the shared `rpgtools-owlbear` package to 0.1.1.
