# Scvm Rack — v0.2.1

**Release date:** 2026-05-31
**Type:** Patch — alpha polish and safer first-run routing

This patch makes the alpha state explicit, hardens the landing-page sheet handoff,
and tightens the production/deploy details found during the latest Lighthouse pass.

---

## Highlights

- **Alpha badge.** The Scvmrack title now carries an `Alpha` badge so testers know
  immediately which release phase they are using.
- **Safer Open Sheet handoff.** The landing CTA now links to a specific character
  only after the app validates or prepares a known-good scvm id. Fast clicks fall
  back to the sheet bootstrap route instead of treating a stale id as missing.
- **Linked production credit.** The landing footer now links `Adam Kościelniak` to
  `adamkoscielniak.me`, with localized credit text preserved.
- **Deploy packaging fix.** The backend deploy preparation now copies the built
  frontend output into the public bundle, so generated static files ship with the
  production artifact.
