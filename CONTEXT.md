# scvmrack

A MÖRK BORG character sheet: players roll and keep scvm, GMs run parties of them.

## Language

### Classes

**Built-in Class**:
A class seeded by scvmrack with no owner: a Book Class, Zine Class or Rack Class.
_Avoid_: default class, official class, system class

**Book Class**:
A Built-in Class from the MÖRK BORG main book.
_Avoid_: MB class, core class

**Zine Class**:
A Built-in Class from a third-party publication, shown with its Credit.
_Avoid_: third-party class

**Rack Class**:
A Built-in Class made by scvmrack itself for the community.
_Avoid_: house class

**Credit**:
The attribution of a Zine Class (or Rack Class) to its work and author, shown as "from {work} by {author}".
_Avoid_: author, source

**Custom Class**:
A class authored by a signed-in GM, owned by that GM's account; shown as "created by {name}".
_Avoid_: homebrew class, user class

**Class Item**:
A weapon, armor, equipment or pet authored inside a Custom Class, grantable only by that class's abilities.
_Avoid_: custom item, homebrew item

**Public Custom Class**:
A Custom Class its author has made visible to other GMs.
_Avoid_: shared class, community class

**Archived Custom Class**:
A Custom Class that can no longer be rolled but still backs the characters already playing it.
_Avoid_: deleted class

### Parties

**Party Class Pool**:
The set of classes (Book and Custom) enabled for one party; the only classes its join flows can roll or forge.
_Avoid_: class list, enabled classes, class setup

**Takedown**:
An admin removing a Public Custom Class after a report.
_Avoid_: ban, deletion
