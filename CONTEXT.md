# scvmrack

A MÖRK BORG character sheet: players roll and keep scvm, GMs run parties of them.

## Language

### Classes

**Book Class**:
One of the built-in MÖRK BORG classes shipped with the app.
_Avoid_: default class, MB class, core class

**Custom Class**:
A class authored by a signed-in GM, owned by that GM's account.
_Avoid_: homebrew class, user class

**Class Item**:
A weapon, armor, equipment or pet authored inside a Custom Class, grantable only by that class's abilities.
_Avoid_: custom item, homebrew item

**Public Custom Class**:
A Custom Class its author has made visible to other GMs.
_Avoid_: shared class, community class

**Archived Custom Class**:
A Custom Class that can no longer be rolled but still backs the characters already playing it.
_Avoid_: deleted class

### Parties

**Party Class Pool**:
The set of classes (Book and Custom) enabled for one party; the only classes its join flows can roll or forge.
_Avoid_: class list, enabled classes, class setup

**Takedown**:
An admin removing a Public Custom Class after a report.
_Avoid_: ban, deletion
