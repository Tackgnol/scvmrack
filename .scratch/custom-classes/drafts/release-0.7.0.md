## Forge your own classes

GMs can now write their own character classes, with everything a Book Class has.

- **The class creator**: seven steps covering identity, stat dice, Class Items, abilities, origins and Getting Better, ending with a test roll of a scvm from your draft.
- **Book parity**:
  - stat dice and modifiers, HP and Omen dice, starting gear and silver
  - fixed and random abilities, each able to grant an item or a pet
  - Class Items only your class has
  - reference tables the player rolls on
- **Porting a zine is fast**: paste an ability list, origins or a table straight from the page, and numbering and headers are cleaned up.
- **Drafts save as you write**, are kept for 90 days, and follow you across devices.
- **Characters never break**: each scvm keeps the version of the class it was rolled with. Saving changes to a class someone plays creates a new version.

## Choose what your warband can roll

- **The class pool**: a new section on the party page chooses which classes players pick from when they join: Book, Zine and Rack Classes, your own, other GMs' public ones, and Classless.
- **Owlbear Rodeo rooms** roll from the room party's pool too, with a class picker in the Roll popover.

## Share them

- **Publish** a class and any GM can add it to their party, credited to you.
- **Anyone can report** a public class, signed in or not. A person reviews every report, and authors can dispute decisions.

## Also in this release

- **Specialist** joins Getting Better: a class's random abilities become specialties, generalising the Gutterborn Scvm rule.
- **Reorder** abilities, Class Items, origins and table rows by dragging, from a Move menu, or with Alt+↑/↓.
- **New pages**: Terms, Contact and a report page, linked from the footer.
- **The GM tab** now shows for everyone; signed-out visitors see what the GM tools do.
